# Учёт зарплат сотрудников

Одностраничное веб-приложение для учёта зарплат по магазинам и сотрудникам с синхронизацией
данных через **Google Таблицы (Google Apps Script)**.

Стек: **React 19 · Vite 7 · TypeScript · Tailwind CSS 4 · Recharts · Lucide React**.
Сборка — единый HTML-файл (`vite-plugin-singlefile`), поэтому приложение можно открыть откуда угодно
и даже положить на любой статический хостинг.

---

## Возможности

| Раздел | Что умеет |
| --- | --- |
| **Дашборд** | KPI (сотрудники, магазины, ЗП за месяц и год), зарплата по месяцам (bar + line, 12 мес.), распределение по магазинам (pie), топ‑5 сотрудников, динамика месяц‑к‑месяцу в %, сводная таблица |
| **Магазины** | Создание, переименование, удаление с каскадным удалением сотрудников и их зарплат, карточки с количеством сотрудников и суммой выплат |
| **Сотрудники** | Создание, редактирование, удаление, привязка к магазину, поиск, фильтр по магазину, сортировка, итоги |
| **Зарплаты** | Сетка «сотрудники × месяцы» выбранного года и магазина, редактируемые ячейки, автоподсчёт по строкам, столбцам и общий итог, сохранение по `Enter` / потере фокуса. Доступные годы: **2020–2040** (задаётся константами `MIN_YEAR` / `MAX_YEAR` в `src/lib/constants.ts`) |
| **Массовая вставка** | Импорт готовой таблицы из Excel / Google Таблиц по **Ctrl+V**: автоопределение месяцев, столбца с магазином, транспонированных таблиц, сумм в любом формате. Сотрудники сопоставляются по фамилии, недостающие магазины создаются |
| **Сравнение периодов** | Месяц к месяцу, квартал к кварталу, год к году: два любых периода (например, 2 квартал 2024 и 2 квартал 2025), разница в ₽ и %, разбивка по месяцам, сотрудникам и магазинам, кнопки сдвига периодов |
| **Отчёты** | Фильтры по сотруднику и магазину, периоды (месяц / квартал / год / произвольный диапазон), сравнение с предыдущим периодом, график динамики, разбивка по сотрудникам и магазинам, экспорт CSV |
| **Настройки** | URL Google Apps Script, ручная загрузка / сохранение, автосинхронизация, экспорт / импорт JSON, демо‑данные, полная очистка, готовый скрипт GAS с кнопкой копирования |
| **Инструкция** | Пошаговое руководство для новичка (таблица → Apps Script → развертывание → GitHub Pages) и разбор частых проблем |

Авторизация: экран входа с паролем администратора. Сессия хранится в `sessionStorage`
(сбрасывается при закрытии вкладки). Пароль задаётся константой `ADMIN_PASSWORD` в
`src/lib/constants.ts`.

## Подключение Google Таблиц

1. Создайте новую таблицу: <https://sheets.new>
2. Меню **Расширения → Apps Script**.
3. Удалите содержимое `Code.gs` и вставьте скрипт из раздела **Настройки → Google Apps Script**
   (там же есть кнопка «Копировать»).
4. Нажмите 💾 **Сохранить**.
5. **Развернуть → Новое развертывание → Веб-приложение**:
   - **Выполнить как:** пользователь, от имени которого создан скрипт;
   - **Доступ:** `Все`.
6. Скопируйте URL вида `https://script.google.com/macros/s/…/exec`.
7. Вставьте его в приложении: **Настройки → URL веб-приложения → Сохранить URL**.
8. Включите «Автосинхронизация» и нажмите «Загрузить из Google».

Скрипт автоматически создаёт и поддерживает три листа:

| Лист | Колонки |
| --- | --- |
| `Stores` | `id`, `name` |
| `Employees` | `id`, `name`, `storeId` |
| `Salaries` | `id`, `employeeId`, `month` (`YYYY-MM`), `amount` |

`doGet` возвращает `{ ok, data: { stores, employees, salaries } }`,
`doPost` принимает `{ data: { stores, employees, salaries } }` и полностью перезаписывает листы.

### Модель данных

```ts
interface Store    { id: string; name: string }
interface Employee { id: string; name: string; storeId: string }
interface Salary   { id: string; employeeId: string; month: string; amount: number }
```

## Массовая вставка из Excel (Ctrl+V)

На странице **«Зарплаты»** нажмите **Ctrl+V** — откроется окно импорта с предпросмотром.

Распознаётся автоматически:

| Что | Примеры |
| --- | --- |
| Месяцы в заголовке | `Январь`, `янв`, `1`, `01.2024`, `2024-01`, `01.01.2024`, `Январь 2024` |
| Суммы | `52 000`, `52000,50`, `52,000`, `(1200)` → −1200, `—` → пусто |
| Разделители | табуляция, `;`, `\|`, `,` |
| Столбец с магазином | по заголовку «Магазин / Точка / Филиал» или по совпадению с существующими названиями |
| Транспонированная таблица | месяцы в строках → разворачивается сама |
| Лишние столбцы и строки | `Итого`, `Всего`, `№` пропускаются |

Опции импорта: «Магазин по умолчанию», «Создавать магазины», «Перезаписывать суммы»,
«Обновлять магазин» (переносит сотрудника в магазин, указанный в строке, — так «Аймашева»
останется именно в своём магазине).

Если заголовков нет — месяцы считаются по порядку, начиная с выбранного в окне импорта.

## Сравнение периодов

Раздел **«Сравнение»**: выбирается тип («Месяц к месяцу», «Квартал к кварталу», «Год к году»)
и два периода A и B. Приложение показывает суммы обоих периодов, разницу в рублях и процентах,
среднюю зарплату, график с парными столбцами по месяцам, таблицу «месяц к месяцу», разбивку
по сотрудникам и по магазинам. Кнопки «A = B − 1 период» и «Период назад / вперёд» ускоряют
выбор типичного сравнения.

## Как работает синхронизация

- Все данные всегда хранятся в `localStorage` — приложение работает офлайн.
- Год для ввода и отчётов можно выбрать любой из диапазона **2020–2040** — переключатель года
  есть на дашборде, в сетке зарплат и в отчётах (в сетке рядом с годом показано количество записей).
- Если указан URL GAS и включена автосинхронизация, при старте выполняется автоматическая загрузка
  из Google Таблиц.
- Любое изменение данных через **1,5 секунды** (debounce) уходит в Google Таблицы.
- Во время загрузки установлен флаг `skipPush`, чтобы только что полученные данные не были сразу
  отправлены обратно.
- Статус синхронизации, время последней загрузки и сохранения видны в сайдбаре, там же кнопки
  «Загрузить / Сохранить».

## Деплой на GitHub Pages

1. Загрузите проект в репозиторий:

   ```bash
   git init
   git add .
   git commit -m "feat: приложение учёта зарплат"
   git branch -M main
   git remote add origin https://github.com/ЛОГИН/salary-app.git
   git push -u origin main
   ```

2. Workflow уже лежит в `.github/workflows/deploy.yml`
   (`npm ci` → `npm run build` → артефакт `dist` → `deploy-pages`).
3. В репозитории: **Settings → Pages → Source: GitHub Actions**.
4. Готово: `https://ЛОГИН.github.io/salary-app/`

> Приложение собирается в один HTML-файл, поэтому дополнительные настройки базового пути не нужны.

## Частые проблемы

- **«Сервер вернул HTML вместо JSON»** — в развертывании доступ не «Все», либо скопирована ссылка
  `/dev` вместо `/exec`.
- **403 / нет доступа** — выберите «Выполнить как: я».
- **Правки скрипта не применяются** — опубликуйте новую версию: *Развернуть → Управление
  развертываниями → Изменить → Новая версия*.
- **«Загрузить» очистил данные** — загрузка заменяет локальные данные содержимым таблицы; если
  таблица пуста, данные обнулятся. Делайте экспорт JSON перед экспериментами.
